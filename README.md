# MyFitMinder Web

A Next.js web application that explains how MyFitMinder works, featuring pages for Privacy Policy and Terms of Service. The design is consistent with the iOS app's dark theme and styling.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Pages

- **Home** (`/`) - Explains how the app works with step-by-step instructions
- **Privacy Policy** (`/privacy`) - Complete privacy policy
- **Terms of Service** (`/terms`) - Complete terms of service

## Design

The design matches the iOS app's color scheme:
- Dark background (#0E1117)
- Teal primary color (#1F8A70)
- Card backgrounds (#161B22)
- Consistent typography and spacing

## Build

To create a production build:

```bash
npm run build
npm start
```
